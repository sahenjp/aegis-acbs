# Aegis Complexity Lab

`research/complexity-lab` は、Aegis の「候補を探す」と「これより良い候補がないことを確認する」を、計算量研究へ持ち込むための独立した研究ブランチです。

## 現在の実装

最初の対象として小規模な MCSP を扱います。真理値表で与えられた Boolean 関数に対し、NAND だけからなる最小回路を完全探索します。

- 真理値表は `uint64` で表し、現在は 1〜6 入力を扱う。
- 探索はゲート数ごとの幅優先探索なので、状態上限や時間制限に到達せず解が得られた場合、そのゲート数はこのモデルで最小。
- 既に得られている信号集合を正規化し、同じ利用可能関数集合を持つ状態を重複排除する。
- `Verify` は回路を独立に再評価する。
- `VerifyMinimal` は候補より小さい全深さを再探索し、最小性をもう一度確認する。
- `Solver` interface を持ち、将来の SAT、CP-SAT、BDD、GPU、分散探索、あるいは理論上の新アルゴリズムへ置き換えられる。

これは P vs NP の証明ではありません。有限サイズの完全探索結果から、そのまま漸近的な回路下界は従いません。

## 実行

```bash
go build -o bin/aegis-lab ./cmd/aegis-lab

# 2入力 AND。x=1100, y=1010 なので AND=1000=0x8
bin/aegis-lab mcsp \
  --inputs 2 \
  --target 0x8 \
  --max-gates 4 \
  --max-states 100000 \
  --verify-minimal
```

NAND 基底ではこの例の最小回路は 2 ゲートです。

## 研究ロードマップ

### 1. 有限サイズ MCSP の基盤

現在の完全 BFS を基準器にし、最小回路、展開状態数、重複排除率、メモリ量を保存します。高速化案は必ずこの基準器と照合します。

### 2. 強い枝刈りと証明可能な下界

探索を速くするだけのヒューリスティックと、枝を安全に捨てられる admissible lower bound を分離します。下界が導入された場合は、枝刈り理由を記録し、再検証可能にします。

### 3. Circuit-SAT と #SAT

制限回路クラスに対する SAT / #SAT 実験を追加します。総当たり `2^n` に対する改善を、入力サイズ、回路サイズ、深さ、ゲート基底ごとに測定します。アルゴリズムから回路下界を導く Williams 型の研究方向と接続する場所です。

### 4. proof complexity

Resolution など、定義と検証器が明確な証明系から最短反駁探索を始めます。単に「証明を見つけた」ではなく、短い証明が存在しない範囲を再現可能に確定することを重視します。

### 5. 予想抽出

難しい関数群について、回路サイズ、support、対称性、探索時の下界推移などを収集します。機械的な相関は定理とは扱わず、一般化可能な補題候補を作るために使います。

## P = NP が解決された場合

このブランチは特定の「P ≠ NP を仮定した探索法」に固定しません。`Solver` と検証器を分離しているため、将来 P = NP が証明され、実用的な多項式時間アルゴリズムが得られた場合は、そのアルゴリズムを新 backend として差し込めます。

ただし P = NP だけでは実用上の最速性は決まりません。多項式次数、定数、メモリ、並列性、前処理、証明生成コストが残るため、既存 backend と新 backend を同一の問題形式と検証器で比較できる設計を維持します。

## 重要な境界

- 現在の NAND 回路モデルは一般的な MCSP 研究の全モデルを代表しない。
- 6 入力制限は真理値表表現の現在の実装上の制限。
- `MaxStates` に達した探索は最小性の証拠に使わない。
- 有限実験の成長曲線を、無限族に対する下界として主張しない。
- 既知の相対化、自然証明、代数化などの障壁を回避したと、実験だけで主張しない。

目標は「P vs NP を解いたように見せる」ことではなく、反例、失敗、下界候補を再現可能な形で積み上げ、一般定理へ変換できる実験基盤を作ることです。
